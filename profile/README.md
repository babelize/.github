### Try it

```bash
npx babelize
```

One command in your project: finds user-facing strings, wraps them, and writes translated locale files. Works with **React, Next.js, Django and static sites**. **Vue and React Native** are in beta.

### Packages

| Package | What it does |
| --- | --- |
| [`@babelize/cli`](https://www.npmjs.com/package/@babelize/cli) | Extract, translate, check and sync locale files from your terminal or CI |
| [`@babelize/mcp`](https://www.npmjs.com/package/@babelize/mcp) | MCP server so AI coding agents can analyze, translate and review your app |
| [`@babelize/sdk`](https://www.npmjs.com/package/@babelize/sdk) | i18n without translation keys: wrap strings, Babelize handles the rest |
| [`@babelize/next`](https://www.npmjs.com/package/@babelize/next) · [`@babelize/vite`](https://www.npmjs.com/package/@babelize/vite) · [`@babelize/metro`](https://www.npmjs.com/package/@babelize/metro) | Build plugins that discover strings and generate the lockfile at build time |
| [`@babelize/elements`](https://www.npmjs.com/package/@babelize/elements) | Open-source React + Tailwind components: language switchers, locale pickers and more |

### Open source

- **[babelize-elements](https://github.com/babelize/babelize-elements)**: copy-paste localization UI components for React and Tailwind
- **[examples](https://github.com/babelize/examples)**: Next.js, React + Vite (SDK), Expo, Django and static HTML apps localized with Babelize
